# Journal — 2026-05-22

## Contexte

Session graphismes. Le rendu du jeu était **saturé, plat et terne**. Objectif
fixé en cours de route : se rapprocher d'un look type **Path of Exile**
(contraste, soleil franc, ombres définies, profondeur atmosphérique) — réf.
visuelle fournie par l'utilisateur.

## Le fil de la session

1. **Sursaturation** — cause trouvée : `DefaultVolumeProfile.asset` poussait un
   grade agressif (postExposure +1.7, Tonemapping None, lift/gamma/gain et
   white balance décalés). Grade neutralisé.
2. **Mauvais URP actif** — le pipeline de rendu actif était le `Universal Render
   Pipeline Asset` d'un **pack tiers** (`3D_Sci-fi_ET_plants`). Bascule sur le
   Pipeline Asset du projet (`Assets/Settings/`).
3. **Lumière plate** — diagnostic : aucun SSAO (objets « en stickers »), ombres
   quasi invisibles, soleil faible, Indirect Multiplier anormalement haut (3.16).
4. **Voile gris** — apparu après le passage du Grading Mode en HDR : le
   Tonemapping *Neutral*, qui ne faisait rien en LDR, s'est mis à délaver
   l'image. Corrigé en passant à **ACES**.
5. **Ombres écrasées** — le « toe » d'ACES claquait les bas-tons au noir pur.
   Rééquilibré en redonnant de la lumière aux ombres (ambiant + Shadow Strength)
   plutôt qu'en cassant le tonemapper.
6. **Re-bake** — le lightmap était périmé (calculé avant les changements de
   lumière). Re-baké pour cohérence ; le look a tenu.

## Décisions de conception

- **Tonemapping ACES** plutôt que Neutral. Le contexte avait changé depuis le
  choix initial de Neutral : Neutral était le bon choix prudent quand le
  problème était la *sur*saturation ; une fois la scène correctement exposée,
  Neutral devient trop mou et ACES apporte le punch filmique recherché.
- **Color Grading Mode HDR** plutôt que LDR : en LDR le tonemapping et le grade
  sont clampés en 0-1 et le tonemapper ne peut pas rouler les hautes lumières.
  En HDR le grade s'applique avant clamp — pipeline filmique correct.
- **Corriger les ombres par la lumière, pas par le grade** : on remet du fill
  (ambiant) dans les ombres plutôt que de lifter les noirs en post — sinon le
  voile gris revient.

## Fait

### Pipeline & post-process
- Bascule sur le bon URP Asset (`GraphicsSettings` + `QualitySettings`).
- `New Universal Render Pipeline Asset` : Color Grading Mode LDR → HDR, LUT 32 → 64.
- SSAO ajouté comme Renderer Feature sur `..._Renderer`.
- `DefaultVolumeProfile` : sursaturation neutralisée ; puis grade final —
  Tonemapping ACES, Contrast +6, Split Toning (ombres froides / hautes
  lumières chaudes), vignette conservée.

### Éclairage de Game.unity
- Directional Light : Intensity 0.8 → 3, Shadow Strength 0.384 → 0.78,
  Indirect Multiplier 3.16 → 1, Soft Shadows Low → High.
- Ambiant skybox : Intensity Multiplier 1 → 1.5 (lisibilité des ombres).
- Lightmap re-baké (Mixed / Shadowmask) pour cohérence.
