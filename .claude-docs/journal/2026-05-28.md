## 2. Peuplement procédural IA du monde (chantier majeur)

L'utilisateur a décidé de supprimer ses NPCs manuels et de laisser l'IA
les générer.

- `NPC_Template.prefab` créé dans `Assets/Resources/` avec les 5 scripts
  standard (NPC + NPCNameDisplay + NPCMovement + NPCQuestTurnIn + Shop)
  + tag NPC + layer Obstacles + Cube mesh URP.
- `WorldNPCPopulator` auto-bootstrappé sur scène Game :
  - Si aucun NPC en scène, scanne les QuestZones, trie par distance au
    joueur, génère pour chaque zone 1-3 PNJ cohérents avec le `zoneType`
    (market → marchand, laboratory → scientifique, etc.).
  - N tiré en amont (`Random.Range(1,4)`) sinon le modèle ancre toujours
    sur le upper bound (3 partout).
  - Filtre IsTemplatePlaceholder pour skip les lignes "nom_complet | role |
    description_courte" que le modèle recopiait en tête.
  - Couleur HSV aléatoire vive (sat 0.55-0.85, val 0.75-1.0).
- `ShopCatalogGenerator` enchaîne après le populator :
  - Trigger explicite via `TriggerNow()` à la fin du populator. Sinon
    race : ShopCatalogGenerator se lance à 2s, voit 0 NPC (populator pas
    fini), s'arrête → 0 catalogue généré.
  - Le populator skip aussi (NPC déjà présents = save load ou manuel) →
    triggers ShopCatalogGenerator quand même.
- Save/load NPC procéduraux : `NPCSaveData` étendu avec npcRole,
  npcDescription, npcColorRGB, shopCatalog. Au load, si l'NPC n'existe
  pas en scène → instancier `NPC_Template` depuis Resources/ et configurer.

## Apprentissages

- **Ollama qwen2.5 est moins discipliné que GPT-4o-mini sur les tokens**.
  Les tokens inline `[SHOP]`, `[PLANET:Nom]` etc. fonctionnent mais avec
  taux d'émission variable. Pour les actions critiques → analyse séparée
  (architecture B2 pour quêtes, C pour shop).
- **Le modèle ancre sur les bornes hautes des intervalles**. "1 à 3 PNJ"
  donne toujours 3. "0 à 5 articles" donne souvent 5. Tirer N en amont
  et demander EXACTEMENT N est plus déterministe.
- **Les exemples concrets dans les prompts sont des aimants à
  copier-coller**. J'ai donné "Velka des Etoiles" et "Korvyn le Cendreux"
  en exemples → le modèle les a recopiés sur 10+ NPCs. Retirer les
  exemples spécifiques, donner des consignes de variation.
- **`WaitForSeconds` est gelée pendant Time.timeScale=0**. Pour le
  gameplay-pause, toujours `WaitForSecondsRealtime` dans les coroutines
  IA-dialogue.
