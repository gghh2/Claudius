# Journal — 2026-05-22

## Contexte

Très longue session en deux actes. **Acte 1** : refonte des graphismes — le
rendu était saturé et plat, objectif un look type *Path of Exile*. **Acte 2** :
premier build Windows depuis la migration Unity 6.2, qui a fait remonter une
cascade de problèmes (build, curseur, sauvegarde, IA) — tous corrigés.

## Acte 1 — Refonte des graphismes

Cible : contraste, soleil franc, ombres définies, profondeur atmosphérique
(réf. PoE fournie par l'utilisateur).

1. **Sursaturation** — cause : `DefaultVolumeProfile.asset` poussait un grade
   agressif (postExposure +1.7, Tonemapping None…). Grade neutralisé.
2. **Mauvais URP actif** — le pipeline actif était celui d'un pack tiers →
   bascule sur le Render Pipeline Asset du projet.
3. **Lumière plate** — SSAO ajouté (ancrage des objets), soleil renforcé,
   ombres rendues lisibles.
4. **Voile gris** — apparu en passant le Grading Mode en HDR : le Tonemapping
   *Neutral* délavait l'image → passage à **ACES**.
5. **Ombres écrasées** — le « toe » d'ACES claquait les bas-tons au noir →
   rééquilibré en redonnant de la lumière aux ombres (ambiant + Shadow
   Strength), pas en cassant le grade.
6. **Re-bake** du lightmap pour cohérence avec la nouvelle lumière.

Décisions : Tonemapping ACES (Neutral devenu trop mou une fois la scène
correctement exposée) ; Grading Mode HDR ; corriger les ombres par la lumière,
pas par le grade.

## Acte 2 — Premier build, et la cascade

1. **Render Graph** — le build refusait le « Compatibility Mode » déprécié.
   Basculé sur Render Graph (aucune passe de rendu custom dans le projet → sans
   risque).
2. **Limite de samplers du shader Lit** — `maximum ps_4_0 sampler register
   index (16) exceeded` : une variante URP/Lit dépassait la limite d3d11 de 16
   textures. Light Cookies + ombres des lumières additionnelles désactivées
   (non utilisées) → repassé sous la limite.
3. **Curseur absent sur MainMenu** — `SmartCursorManager` forçait le curseur
   caché quand aucun `UnifiedUIManager` n'est présent (cas du menu). Corrigé.
4. **« Continue » cassé** — `MainMenuUI.ContinueGame()` appliquait la save
   avant le chargement de la scène Game (joueur introuvable). Chargement
   différé via le flag `LoadOnStart`, lu par `GameLoadingManager`.
5. **IA en fallback** — saga en trois temps :
   - `gpt-4o-mini` retiré côté OpenAI → `gpt-5.4-mini`.
   - Le projet OpenAI bloquait *tous* les modèles → débloqué côté dashboard
     (Limits → Allow). Diagnostic facilité en logguant le corps de réponse HTTP.
   - GPT-5.x rejette `max_tokens` → renommé `max_completion_tokens`.
   - Vérifié par `curl` : la requête exacte du jeu répond 200.
6. **Crash de build via `AssetManagerTester`** — un `async void` reprenait
   après un `await` sur un objet détruit → `MissingReferenceException`.
   Garde-fou `this == null` ajouté.

Leçon retenue : éditer les `.asset` de réglages Unity pendant que l'éditeur
tourne ne s'applique pas de façon fiable — il a fallu **redémarrer Unity**.
