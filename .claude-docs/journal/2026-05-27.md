- **Anti-hallucination IA v2** (même commit `a07a230`). Le v1 ratait pour
  deux raisons :
  1. Les phrases d'exemple entre guillemets (« Je ne vois rien de tel sur
     vous », « Montrez-moi vraiment »...) étaient **recopiées verbatim**
     par le modèle. Classic prompt-engineering anti-pattern.
  2. La règle ne couvrait que « j'ai trouvé un X » — quand le joueur disait
     « regardez le ! » sans nommer l'objet, l'IA caquait et hallucinait
     l'apparence (« faces étrangement brillantes... »).
  Fix : RÈGLE ABSOLUE intégrée dans `BuildSystemPrompt` (les 2 branches),
  pas seulement dans InjectInventoryContext. Suppression de toutes les
  phrases d'exemple. Couverture explicite des références vagues
  (« regardez », « tenez », « voici »...).
  Validé en jeu avec Arcan : « Si tu **avais** ces cristaux » (conditionnel
  correct), plus aucune description hallucinée, formules variées.

- **Autocompletion des références familières dans le dialogue**
  (commit `4d91d66`, validé en jeu). Quand le joueur tape >= 3 lettres qui
  prefixent une référence connue (item porté, item déjà eu, zone découverte,
  PNJ rencontré, note lue), un bandeau apparaît au-dessus de l'input
  field : `[TAB] Lettre inachevée`. TAB valide. Idée du user, excellente
  parade aux hallucinations futures : on ne peut référencer que des trucs
  réels.
  - `KnownReferenceProvider.cs` (static) agrège les 5 sources
  - `DialogueAutocomplete.cs` créé le bandeau et écoute onValueChanged
  - `PlayerInventory.EverPossessedItemNames` (HashSet) couvre les items
    déjà donnés/utilisés
  - Auto-attache via `DialogueUI.Awake` en fallback

- **MCP UnityMCP utilisé intensivement** pour lire la conversation IA
  vivante d'Arcan via `execute_code` + réflexion. Indispensable pour
  diagnostiquer le perroquetage et la chute du « regardez le ! ».

## Apprentissages

- **Quand on cite des phrases d'exemple entre guillemets dans un prompt,
  le LLM les recopiera verbatim** (Gemini 2.5 / GPT-5 idem, c'est pas une
  bizarrerie de gpt-4o-mini). Décrire le comportement attendu, pas les
  mots exacts.

- **Le system prompt d'une conversation IA n'est appliqué qu'à la
  première ouverture**. Tant qu'un cache existe (conversationsByNpc), le
  vieux prompt persiste. Pour tester un nouveau prompt vite : vider le
  cache pour le NPC concerné via execute_code MCP.

- **Le BACKLOG peut être en retard sur la réalité**. Le check `git grep`
  d'une règle vaut mieux qu'un rappel mémoire. Pris l'habitude de vérifier
  avant de prévoir du temps sur un "fix mécanique".
